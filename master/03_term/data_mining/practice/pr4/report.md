## 1. Цель и задачи работы

**Цель:** освоить методы текстового анализа и определения тональности текстов в системе PolyAnalyst.

**Задачи:**

1. Подготовить обучающую выборку размеченных текстовых отзывов.
2. Извлечь признаки: мешок слов и ключевые фразы.
3. Обучить классификатор отзывов на три класса: положительные, отрицательные, нейтральные.
4. Оценить качество модели: рассчитать accuracy, precision, recall.
5. Найти наиболее значимые слова для классификации.
6. *(Дополнительно)* Сравнить rule-based подход и машинное обучение.

### 2.2. Обоснование выбора

В условии практики 4 указано, что данные те же, что в практике 3, то есть открытые отзывы на товары, фильмы, услуги. Набор отзывов на фильмы подходит по предметной области. Критерии выбора:

1. **Три размеченных класса.** Задача требует положительные, отрицательные и нейтральные отзывы. В выбранном наборе нейтральный класс размечен.
2. **Достаточный объём.** Даже при выравнивании классов по наименьшему (4 576 нейтральных) остаётся несколько тысяч примеров на класс. Этого достаточно для обучения и честной проверки на отдельной тестовой выборке.
3. **Опубликованный источник** с описанием структуры и ссылкой на научную работу.
4. **Открытая лицензия** (MIT).

**Рассмотренные и отклонённые варианты:**

- *Новостной корпус NTI (Kaggle).* В таком наборе, как правило, нет разметки тональности, а без неё нельзя обучить классификатор и посчитать метрики. Разметка «вручную» или по правилам сделала бы оценку модели условной.
- *`zloelias/kinopoisk-reviews-short` (Hugging Face).* Всего 328 отзывов (295 в train, 33 в test) и только два класса (positive, negative): нейтрального класса нет. На 33 тестовых примерах одна ошибка меняет accuracy примерно на 3 п.п., поэтому метрики были бы статистически ненадёжны. В выборке также отмечены расхождения между текстом и меткой и остатки оценок в тексте («9/10», «5*»).

### 2.3. Особенности и ограничения набора

- Отзывы взяты только из рейтингов TOP250 и BOTTOM100, поэтому выводы относятся к такому типу отзывов, а не к любым.
- Класс Good составляет около 75% данных. Это потребовало выравнивания классов (см. раздел 3).
- Разметка `grade3` получена из исходных данных Кинопоиска, а не вручную для задачи. Нейтральные отзывы нередко содержат и положительные, и отрицательные оценки, поэтому класс Neutral ожидаемо самый трудный для модели.
- Отзывы разной длины (от нескольких десятков до тысяч символов).

### 8.3. Метрики

Формулы (для класса *c*; TP — верно найденные, FP — ложно отнесённые к классу, FN — пропущенные):

- **Accuracy** = (число верных предсказаний) / (число всех документов);
- **Precision(c)** = TP(c) / (TP(c) + FP(c)) — какая доля документов, названных моделью классом *c*, действительно ему принадлежит;
- **Recall(c)** = TP(c) / (TP(c) + FN(c)) — какую долю реальных документов класса *c* нашла модель;
- **Macro-усреднение** — простое среднее значений по трём классам.

## Приложение А. Скрипт подготовки данных

```python
import pandas as pd

df = pd.read_json("hf://datasets/blinoff/kinopoisk/kinopoisk.jsonl", lines=True)
df = df.dropna(subset=["content", "grade3"])
df = df.drop_duplicates(subset="review_id").drop_duplicates(subset="content")

# чистка: убираем «утёкшие» оценки и лишние пробелы, обрезаем длину
leak = r"\b\d{1,2}\s*(?:/|из)\s*10\b|\b\d{1,2}\s*баллов?\b|\b\d\s*\*"
df["text"] = (df["content"]
              .str.replace(leak, " ", regex=True)
              .str.replace(r"\s+", " ", regex=True)
              .str.strip()
              .str.slice(0, 1000))
df = df[df["text"].str.len() >= 100]

print(df["grade3"].value_counts())  # проверка: какие значения и сколько

# сбалансированная случайная выборка
N = 1500
N = min(N, df["grade3"].value_counts().min())
sample = (df.groupby("grade3").sample(n=N, random_state=42)
            .sample(frac=1, random_state=42)
            .reset_index(drop=True))

sample["label"] = sample["grade3"].map(
    {"Good": "positive", "Neutral": "neutral", "Bad": "negative"})
print(sample["label"].isna().sum(), "строк без метки (должно быть 0)")

# стратифицированное разбиение 70/30
test_idx = sample.groupby("label").sample(frac=0.3, random_state=42).index
sample["set"] = "train"
sample.loc[test_idx, "set"] = "test"

# сохранение
cols = ["review_id", "text", "label", "set"]
sample[cols].to_csv("kinopoisk_3class.csv", index=False, encoding="utf-8")
sample[sample["set"] == "train"][cols].to_csv("kinopoisk_train.csv", index=False, encoding="utf-8")
sample[sample["set"] == "test"][cols].to_csv("kinopoisk_test.csv", index=False, encoding="utf-8")

print(sample.groupby(["set", "label"]).size())
```
