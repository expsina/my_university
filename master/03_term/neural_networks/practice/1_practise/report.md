# Отчет о практике: обучение перцептрона для моделирования булевой функции

## Цель работы

Целью работы является реализация перцептрона с пороговой функцией активации и трех алгоритмов его обучения (классическое правило коррекции весов, метод Монте-Карло, метод имитации отжига), а также сравнение качества полученных моделей на обучающем и тестовом множествах. Реализация выполнена на языке Python с использованием библиотек NumPy и scikit-learn (последняя применялась только для разделения выборки).

## 1. Формирование множества данных

В качестве целевой функции от шести булевых переменных $x_1, \ldots, x_6$ выбрана функция

$$
y = (x_1 \wedge x_2) \vee x_4 \vee x_6 .
$$

Переменные $x_3$ и $x_5$ на значение функции не влияют, то есть являются фиктивными.

Функция является линейно разделимой. Например, для весов $w = (0{,}4;\ 0{,}4;\ 0;\ 0{,}6;\ 0;\ 0{,}6)$, смещения $b = 0$ и порога $0{,}5$ правило

$$
\hat{y} = \begin{cases} 1, & \sum_{i=1}^{6} w_i x_i + b > 0{,}5, \\ 0, & \text{иначе}, \end{cases}
$$

воспроизводит функцию на всех 64 возможных наборах: сумма превышает порог, только если выполнено $x_1 \wedge x_2$ (сумма не меньше $0{,}8$), либо $x_4 = 1$, либо $x_6 = 1$ (сумма не меньше $0{,}6$); одиночное $x_1$ или $x_2$ дает $0{,}4$, что меньше порога.

Множество данных получено генерацией 200 случайных наборов значений шести переменных (генератор псевдослучайных чисел с начальным значением 42, каждая переменная принимает значение 1 с вероятностью $0{,}5$). Для каждого набора значение функции вычислялось по формуле выше. Теоретическая доля нулевых значений равна $3/16 = 18{,}75\,\%$, единичных $81{,}25\,\%$. В полученной выборке доля истинных значений составила $83{,}5\,\%$, ложных $16{,}5\,\%$, то есть требование не менее $10\,\%$ каждого класса выполнено.

| Показатель | Значение |
|---|---|
| Число переменных | 6 |
| Число строк в выборке | 200 |
| Доля истинных значений | 83,5 % |
| Доля ложных значений | 16,5 % |

## 2. Разделение на обучающее и тестовое множества

Выборка разделена функцией train_test_split в соотношении 80 % и 20 % (параметр random_state равен 42). Получено 160 строк обучающего и 40 строк тестового множества.

## 3. Реализация алгоритма обучения перцептрона

Перцептрон реализован в виде класса. Выход вычисляется по формуле

$$
\hat{y} = \begin{cases} 1, & \mathbf{w}^{T}\mathbf{x} + b > 0{,}5, \\ 0, & \text{иначе}. \end{cases}
$$

Начальные веса и смещение задаются случайно из равномерного распределения на отрезке $[0; 1]$. Обучение выполняется по эпохам. На каждой эпохе последовательно просматриваются все строки обучающего множества, и для каждой строки $i$ параметры корректируются по правилу

$$
\mathbf{w} \leftarrow \mathbf{w} - \eta\,(\hat{y}_i - y_i)\,\mathbf{x}_i, \qquad b \leftarrow b - \eta\,(\hat{y}_i - y_i),
$$

где $\eta$ является шагом обучения. Если предсказание верно, параметры не меняются. Критерий остановки: на очередной эпохе нет ни одной ошибки, либо достигнуто максимальное число эпох (1000).

В качестве функции ошибки для всех методов используется число неверно классифицированных строк:

$$
E(\mathbf{w}, b) = \sum_{i} (\hat{y}_i - y_i)^2 .
$$

Качество модели оценивается долей правильных ответов (accuracy); ошибка в процентах равна $100\,\% - \text{accuracy}$.

## 4. Обучение при различных значениях шага

Обучение проведено при трех значениях шага $\eta = 0{,}01;\ 0{,}1;\ 1{,}0$ с одинаковой начальной инициализацией (начальное значение генератора равно 42). Во всех случаях алгоритм сошелся, поэтому корректировка множества данных не потребовалась.

| Шаг обучения | Число эпох до сходимости | Точность на обучающем множестве | Точность на тестовом множестве | Ошибка на обучающем множестве | Ошибка на тестовом множестве |
|---|---|---|---|---|---|
| 0,01 | 16 | 100 % | 100 % | 0 % | 0 % |
| 0,1 | 4 | 100 % | 100 % | 0 % | 0 % |
| 1,0 | 3 | 100 % | 100 % | 0 % | 0 % |

Полученные веса:

| Шаг обучения | Веса модели |
|---|---|
| 0,01 | 0,295; 0,391; 0,182; 0,719; 0,026; 0,616 |
| 0,1 | 0,375; 0,351; 0,032; 0,799; -0,144; 0,756 |
| 1,0 | 1,375; 1,951; -0,268; 3,599; 0,156; 4,156 |

С ростом шага обучения число эпох до сходимости уменьшается (с 16 до 3). При этом большие значения шага приводят к большим по модулю весам. Веса при фиктивных переменных $x_3$ и $x_5$ во всех случаях остаются малыми по сравнению с весами при значимых переменных $x_1, x_2, x_4, x_6$ и в ряде случаев принимают отрицательные значения, что не влияет на результат классификации.

## 5. Обучение методом Монте-Карло

Алгоритм основан на случайном поиске. Генерируется $N = 10000$ наборов параметров $(\mathbf{w}, b)$, каждая компонента которых выбирается равномерно из отрезка $[0; 1]$. Для каждого набора вычисляется ошибка $E$ на обучающем множестве, и выбирается набор с наименьшей ошибкой.

| Метод | Точность на обучающем множестве | Точность на тестовом множестве | Ошибка на обучающем множестве | Ошибка на тестовом множестве |
|---|---|---|---|---|
| Монте-Карло, $N = 10000$ | 100 % | 100 % | 0 % | 0 % |

Найденные веса: 0,303; 0,288; 0,008; 0,743; 0,145; 0,521.

Метод нашел параметры с нулевой ошибкой. Это объясняется тем, что множество правильных решений для данной функции достаточно велико, а допустимые значения параметров ограничены отрезком $[0; 1]$, в котором такие решения существуют (например, приведенный в разделе 1 набор весов).

## 6. Обучение методом имитации отжига

Решением на каждом шаге служит набор параметров $(\mathbf{w}, b)$. Начальное решение выбирается случайно из $[0; 1]$. Соседнее решение получается добавлением к каждому параметру случайной величины, равномерно распределенной на отрезке $[-\varepsilon; \varepsilon]$, где $\varepsilon = 0{,}1$. Пусть $\Delta = E_{\text{new}} - E$. При $\Delta \le 0$ новое решение принимается всегда, а при $\Delta > 0$ принимается с вероятностью

$$
p = e^{-\Delta / T} .
$$

Параметры метода: начальная температура $T_{\max} = 100$, число итераций при фиксированной температуре $L = 50$, коэффициент охлаждения $r = 0{,}95$ (закон $T \leftarrow rT$), минимальная температура $10^{-10}$. Процесс прекращается досрочно, когда ошибка становится равной нулю. После завершения отжига найденные параметры передаются в качестве начальных в алгоритм обучения из раздела 3; он подтвердил отсутствие ошибок уже на первой эпохе, то есть дополнительной коррекции весов не потребовалось.

| Метод | Точность на обучающем множестве | Точность на тестовом множестве | Ошибка на обучающем множестве | Ошибка на тестовом множестве |
|---|---|---|---|---|
| Имитация отжига | 100 % | 97,5 % | 0 % | 2,5 % |

Отжиг завершился при температуре $T \approx 2{,}38$ с нулевой ошибкой на обучающем множестве. Найденные веса: 0,559; 0,311; 0,062; 1,207; -0,244; 1,098. На тестовом множестве допущена одна ошибка из 40 строк.

## 7. Сравнение результатов

| Метод | Ошибка на обучающем множестве | Ошибка на тестовом множестве | Особенности |
|---|---|---|---|
| Перцептрон, $\eta = 0{,}01$ | 0 % | 0 % | 16 эпох |
| Перцептрон, $\eta = 0{,}1$ | 0 % | 0 % | 4 эпохи |
| Перцептрон, $\eta = 1{,}0$ | 0 % | 0 % | 3 эпохи, наибольшие по модулю веса |
| Монте-Карло, $N = 10000$ | 0 % | 0 % | 10000 вычислений ошибки по всей выборке |
| Имитация отжига | 0 % | 2,5 % | одна ошибка на тесте |

Все методы достигли нулевой ошибки на обучающем множестве, что ожидаемо для линейно разделимой функции. Классический алгоритм обучения перцептрона оказался самым экономичным по числу вычислений: ему потребовалось от 3 до 16 проходов по 160 строкам. Метод Монте-Карло потребовал 10000 вычислений ошибки по всему обучающему множеству, то есть заметно больше вычислений, а его результат зависит от удачи при случайной генерации и от размера области допустимых значений параметров. Метод имитации отжига также достиг нулевой ошибки на обучении, но в отличие от остальных методов дал одну ошибку на тестовом множестве. Вероятная причина состоит в том, что и отжиг, и случайный поиск останавливаются на первом найденном решении с нулевой ошибкой, которое может лежать близко к разделяющей границе, а обучающее множество из 160 строк может не содержать всех 64 возможных наборов значений. Следует учитывать, что тестовое множество невелико (40 строк), поэтому одна ошибка соответствует $2{,}5\,\%$ и является слабым основанием для окончательных выводов о превосходстве или отставании метода.

## 8. Выводы

1. Для линейно разделимой булевой функции $y = (x_1 \wedge x_2) \vee x_4 \vee x_6$ перцептрон с пороговой активацией способен безошибочно воспроизвести значения функции; все три рассмотренных алгоритма обучения нашли такие параметры.
2. Классическое правило обучения перцептрона сходится за небольшое число эпох при любом из трех проверенных шагов обучения. Увеличение шага ускоряет сходимость (16, 4 и 3 эпохи для $\eta = 0{,}01;\ 0{,}1;\ 1{,}0$), но приводит к росту абсолютных значений весов.
3. Методы глобальной оптимизации (Монте-Карло и имитация отжига) также позволяют обучить перцептрон, не используя информацию о направлении коррекции весов, но требуют существенно большего числа вычислений функции ошибки и зависят от выбора гиперпараметров (число испытаний $N$, параметры температурного режима).
4. Качество на тестовом множестве оказалось наилучшим (100 %) у классического алгоритма и метода Монте-Карло; у метода отжига оно составило 97,5 %. Различие соответствует одной строке тестовой выборки.
5. Для линейно разделимых задач предпочтительным является классический алгоритм обучения перцептрона как наиболее быстрый и простой. Методы Монте-Карло и имитации отжига имеют смысл главным образом тогда, когда функция ошибки недифференцируема или не допускает простого правила коррекции весов.
